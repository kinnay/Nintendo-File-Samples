This folder contains test cases for the [BYAML file format](https://nintendo-formats.com/libs/common/byaml.html). Currently, tests are available for BYAML version 1 to 5.

| File | Description |
| --- | --- |
| `empty.byaml` | A basic file that contains an empty dictionary. |
| `values.byaml` | A file that contains basic data types, such as integers and strings. |
| `values_v5.byaml` | A file that contains basic types that were added in later BYAML versions, such as binary data, unsigned integers and 64-bit values. |
| `collections.byaml` | A file that contains an array and a dictionary. |
| `little_endian.byaml` | A file that uses little-endian byte order. |
| `mariokart8.byaml` | A file that uses the binary data table that is only seen in Mario Kart 8. |
| `cycle.yaml` | A file that contains an array and dictionary that refer to each other in a cycle. |
