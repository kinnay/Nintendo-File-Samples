## Nintendo File Samples
> This repository is not affiliated with Nintendo. It is based on independent research by fans.

This repository contains example files for a few files formats that are seen in Nintendo games. 
The goal is to cover various edge cases so that this repository can be used as a test suite for your tools. Documentation of the file formats can be found [here](https://nintendo-formats.com).

Ideally, this repository would contain original files from Nintendo games. However, to avoid copyright issues, we are manually crafting example files with the [Jungle package](https://github.com/kinnay/Jungle.git) instead. The source code that was used to generate the example files can be found in [generate_files.py](https://github.com/kinnay/Nintendo-File-Samples/blob/main/generate_files.py).

If you discover a mistake in one of the test cases, or would like to suggest a new test case, please create an [issue](https://github.com/kinnay/Nintendo-File-Samples/issues) on GitHub.
